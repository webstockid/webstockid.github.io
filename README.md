## 🌟 Tentang Stock ID

**Stock ID** adalah platform *trading suite* modern yang dirancang khusus untuk memenuhi kebutuhan trader saham di Bursa Efek Indonesia (IHSG). Menggabungkan antarmuka interaktif bertema *Dark Mode Glassmorphism*, indikator analisis mutakhir, serta alat bantu eksekusi trading yang terukur dan disiplin.

---

## ⚡ Fitur Utama & Keunggulan

* **Whale Detector & Trade Flow Radar**: Membaca pergerakan *big money* (whales) dan aliran akumulasi/distribusi saham.
* **Smart RRR & Position Sizing**: Kalkulasi rasio *Risk-to-Reward* otomatis untuk menjaga *money management* tetap terukur.
* **Notification & Service Worker Sync**: Pengingat otomatis sisa durasi VIP berbasis PWA / Web Push Notification.
* **Modern Dark Glassmorphism UI**: Tampilan visual elegan dengan paduan warna *emerald* dan font *Comfortaa* yang nyaman di mata.
* **Performa Ringan & Cepat**: Dibangun menggunakan *Vanilla JavaScript* dan *Tailwind CSS* untuk eksekusi tanpa beban dependensi berat.

---

## 💻 Teknologi yang Digunakan

* **Frontend**: HTML5, Vanilla JavaScript (ES6+), Tailwind CSS v4.
* **UI & Stylings**: Glassmorphism Effect, Comfortaa Fonts, FontAwesome 6, Lucide Icons.
* **Backend & Security**: Cloudflare Workers (CORS Proxy & Token Handling), Service Worker API.
* **Hosting**: GitHub Pages.
